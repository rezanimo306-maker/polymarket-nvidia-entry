# polymarket-nvidia-ceo-forecast-01

Forecasts Polymarket's "Next CEO of NVIDIA?" Yes prices minute by minute, 4 hours ahead, as five quantiles per market per minute — built from each market's own recent price history, no model calls, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
